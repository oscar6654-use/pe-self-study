# 身體診察技巧・PE 工作坊網頁

國防醫學院・三軍總醫院醫學生臨床能力教案，整理成兩份可獨立使用的互動網頁。純前端 HTML／CSS／JavaScript，不需要資料庫或後端，離線也能開啟。

## 檔案說明

| 檔案 | 用途 | 適用場景 |
|---|---|---|
| `pe-self-study.html` | 自學講義版：每站以敘事方式說明「為什麼要這樣做」，搭配原創圖解與正常/異常對照，結尾是不打分數的自我檢核清單 | 課前自學、學生自行複習 |
| `pe-osce-checklist.html` | OSCE 測驗評核版：每站對照官方附件二評核表，可即時打分並顯示通過／未通過 | 帶教老師現場評分、工作坊考核 |

兩份涵蓋的 13 站相同：呼吸系統、心血管系統、神經系統、眼睛（眼底鏡）、耳朵（耳鏡）、頸部及甲狀腺、咽喉、乳房、腹部、腹股溝、男性生殖系統、直腸指診、淋巴節。

## 使用方式

### 方式一：直接開啟
雙擊檔案，用瀏覽器打開即可，不需要網路連線。

### 方式二：發布成網頁（建議用於協作平台嵌入）
1. 上傳兩個檔案到 GitHub Pages（或其他靜態網頁空間）。
2. 在 Google 協作平台編輯頁面，選「插入 → 嵌入 → **依網址**」，貼上 GitHub Pages 網址。
   - 請用「依網址」而不是「貼上程式碼」——後者會把頁面塞進固定高度的 iframe，手機瀏覽時容易出現雙層捲動、版面跑掉的問題。
3. 發布協作平台頁面，把協作平台網址分享給學生。

## 技術備註

- 單一 HTML 檔案內含全部 CSS／JavaScript，無外部相依套件，複製檔案即可用。
- 已針對手機（≤900px）做響應式處理：側邊站別選單預設收合，點按鈕展開。
- 兩份文件皆為離線可用，不會將任何資料傳出或存檔；自我檢核與評分狀態僅存在瀏覽器當前畫面中，重新整理即清空。
